# 👟 KicksLine — 足元から振り返る、自分のライフヒストリー

人生で履いてきたスニーカー・革靴・ブーツ・サンダル・部活シューズを時系列で記録・可視化し、当時の年齢や思い出とともに振り返り、1枚の「マガジン風ポスター画像」としてSNSにシェアできるWebアプリケーションです。

🌐 **公開URL**: https://kaito2000.github.io/KicksLine/

## 主な機能

- **4つのカテゴリ区分 ＆ 連動フィルタリング**
  - `スニーカー` / `革靴・ブーツ` / `サンダル` / `スポーツ・部活` のカテゴリごとに絞り込み可能（統計・最長寿の相棒・ポスター出力も選択カテゴリに自動連動）
- **2つの年表ビュー（タブ切替 / 最新順表示）**
  - **縦型カード年表 (STORY)**：履き始めた年・当時の年齢・時代タグ（`#高校時代` `#初任給` `#一生モノの革靴`など）・思い出エピソードをじっくり振り返るアーカイブビュー
  - **着用期間バー (ROTATION)**：西暦ごとの着用期間をガントチャート風に可視化し、同時期にどの靴をローテーションしていたかが一目でわかるマトリクスビュー
- **かんたんビジュアル登録（写真コピペ ＆ 7種のシルエット）**
  - **Web画像検索＆コピペ取り込み**：「🔍 入力したモデル名でWeb画像検索」からコピーした画像を `Ctrl+V` で1秒取り込み（または端末の写真ファイル選択・自動リサイズ圧縮）
  - **7種のシルエット＆14色パレット**：写真が残っていない昔の靴も、7種類の専用シルエット（Low / High / Runner / Canvas / Boots / Leather / Sandal）× 定番カラーパレットでスタイリッシュに表示
- **コレクション統計・インサイト**
  - 通算足数・現役ローテ数、ブランド別シェア比率バー、最長寿の相棒（最長着用モデル）の自動算出
- **SNSシェア用「マガジン風ポスター画像」出力**
  - プライバシーに配慮し、書き出し時に「年齢表示のON/OFF」「思い出メモ表示のON/OFF」「テーマ切替（ホワイトアーカイブ / ダークマガジン）」を選択して高画質PNGとして保存可能
- **ブラウザ内保存（IndexedDB）＆ JSONバックアップ**
  - サーバー不要でブラウザ内に自動保存。端末移行やバックアップ用のJSONエクスポート／インポート機能搭載

## ローカル開発手順

```bash
npm install
npm run dev
```

## GitHub Pages への公開手順

このリポジトリには `.github/workflows/deploy.yml` が含まれています。

1. GitHub リポジトリへ Push します（`main` ブランチ）。
2. GitHub リポジトリ（`https://github.com/kaito2000/KicksLine/settings/pages`）を開きます。
3. **Build and deployment > Source** を **`GitHub Actions`** に変更します。
4. 自動的にビルド＆デプロイが実行され、`https://kaito2000.github.io/KicksLine/` で公開されます。
